## Changing the colors

### Color scheme

- Default: light

```yml
theme:
  theme_style: light
```

<button class="color-button" data-theme="light">
    <code class="swatch-outline-white">light</code>
</button>
<button class="color-button" data-theme="dark">
    <code class="swatch-fill-black">dark</code>
</button>

### Primary color

- Default: black

```yml
theme:
  colors:
    primary: black
```
